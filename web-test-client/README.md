# web-test-client — 微喵歌词同步 测试显示端

协议 v1 的参考网页客户端（纯 ES5 单文件，无构建工具），用于在电脑 / 平板 / 车机浏览器上
验证手机端「微喵歌词同步」的歌词同步与逐字高亮。协议规范见仓库根 `docs/web-protocol.md`。

## 用法

手机上安装 App 后（服务默认常开，默认端口 8765），本页面有三种打开方式：

1. **双击直接打开** `index.html`（file:// 协议也可用），点左上角 ⚙ 填手机地址
   `192.168.x.x:8765` → 点「连接」；地址会记住，下次自动连。
2. **带参数打开**：`index.html?host=192.168.1.5:8765`（适合做成车机书签）。
3. **由 App 直接提供**：在浏览器打开 `http://<手机IP>:8765/` —— App 内置了一个
   极简信息页，提示用本目录的客户端连接。

> 注意：浏览器跨源连接 `http://手机IP:8765` 需要手机与显示设备在同一局域网；
> REST 接口已带 `Access-Control-Allow-Origin: *`，WebSocket 无跨源限制。

## 无手机调试（mock-server）

`mock-server.js` 实现了同一协议的模拟服务器（含切歌回放），用于离线调试页面：

```
node mock-server.js          # 默认端口 18903
```

然后浏览器打开 `index.html?host=localhost:18903`。脚本会先推歌曲 A，
800ms 后切换到歌曲 B，用于验证切歌/逐字渲染。

## 页面功能

- 逐字高亮（双层词级裁剪，词内按音节时长线性填充）
- ⚙ 设置：字号 / 基色 / 高亮色 / 字体族 / 翻译 / 下一句（存 localStorage，按设备各自记忆）
- 键盘 ←/→ 微调歌词时间（±250ms，仅本机）
- 右上角连接点：青=WS 已连 / 灰=重连中；无 WebSocket 的老浏览器自动降级 1s 轮询
- 每 2s ping/pong 校时（最近 5 次取中位数），本地插值保证 60fps 平滑
